# Roy Miller AI Assistant

A personal AI assistant built for research, workflow support, document analysis, memory, and task execution.

## What it does
- supports research and workflow tasks
- helps with document and screenshot analysis
- uses persistent memory and tool access
- works through a messaging interface

## Why I built it
I wanted to explore how AI can move beyond chat and become a practical workflow system. This project reflects my interest in applied AI, solutions engineering, and innovation.
